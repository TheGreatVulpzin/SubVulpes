# Security policy

Do not open a public issue for a vulnerability.
Use the SubVulpes repository Security tab and choose Report a vulnerability, if private reporting is available.
If that option is absent, ask the maintainer for a private contact without publishing exploit details.
Include the affected commit, steps with synthetic inputs, and the impact.

Reports include malformed packets or files that crash the server, buffer errors and unauthorized admin actions.
Only `main` receives fixes. Planned policy changes appear in [the plan](docs/plano.md) and [ideas](docs/ideas.md).

Never attach passwords, tokens, `config.txt`, accounts, player captures or proprietary game files.
Use public defaults and synthetic data. Redact names and IP addresses from logs.
