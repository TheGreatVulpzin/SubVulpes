SubVulpes Server

This package contains the Windows x86 server, launcher, plugins and data/. The launcher creates config.txt on first use.
1. Extract the package into a new folder.
2. Open subvulpes_launcher.exe. The window title is SubVulpes Server.
3. Open Server settings. Set the name, UDP port and admin password. Click Save.
4. Open Server. Click Start. Join with a Sub Rosa 0.24 client.
5. Click Stop before closing the launcher.

The launcher makes an admin password on first use. Show reveals or masks the field.
The launcher does not start the server with an empty password. Keep config.txt private after you save settings.
For Internet play, allow the selected UDP port. The default port is 27584.
The launcher checks SubVulpes releases and verifies update checksums.
For manual updates, close the server and launcher. Copy only subvulpes_server.exe,
subvulpes_launcher.exe, LEIA-ME.txt and version.txt. Keep data/, user/, config.txt and readme.txt.
Save Log exports the current server log. Check logs before sharing them.
Debug captures can contain player names, IP addresses and chat. Keep them private.
