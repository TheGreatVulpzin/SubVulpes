## Source and import

Based on OpenSubRosa24 at `svs-base`, commit `eb68519b0982583e188ceb619ff49f14f332e6d9`.
`git filter-repo` was not installed. The new repository uses one source import, without the upstream history.

Copied:

- All of `src/`, including the required runtime tables, initial data and frozen headers.
- `tools/launcher`, `tools/release`, the adapted build script, privacy check, CI and release workflows.
- `tools/re/gen_types.py` and all of `analysis/structs`.
  Two required generator inputs, `globals.csv` and `manual_globals.csv`, moved from `analysis/024d` into `analysis/structs`.
- `docs/game`, plugin design and the applicable SubVulpes ideas.
- GPL-3.0 license, adapted contribution and security policies, and a reduced CMake build.

New: README, local development rules, agent rules and the S0 through S4 plan.
The server retains function dispatch and image-backed globals for S1 and S2.
No plugin API, RCON, dynamic pool or anti-cheat feature is implemented in S0.

Excluded:

- Instrumentation, hooks, lifter, gate, differential harness and recorder target.
- Proprietary binaries, game files, recordings, private configuration and account data.
- Third-party server manager files and DLLs, other analysis directories and Ghidra tools.
- Upstream build output. Local build output and downloaded data stay in ignored `build/`.

Only `src/standalone/main.c` and `src/include/sr_globals_024d.h` differ from the source tag.
The former drops excluded recording branches and changes branding. The latter names the relocated generator input.
Game logic, function tables, initial image tables and the frozen layout remain unchanged.

## Limits and risks

- The launcher visual check relies on user confirmation. Native UI control is unavailable.
- Startup and an idle minute do not prove gameplay or network compatibility under load.
- The server remains 32-bit, with image-backed globals, a large memory region and function dispatch.
- The public admin password is empty. Set a password before public use. Test settings remain local and ignored.
- A10, D11 and D12 need definitions before S3. Other planned policy changes remain open.
- Plugin isolation and native crash recovery are design proposals, not safety guarantees.
- Approved release data has separate ownership. GPL covers project code, not game assets.
- Release workflows were checked locally but were not run on GitHub. That requires a later push.
